# 🛡️ Admin Dashboard

The admin dashboard provides:

- System statistics (users, tickets, surveys, etc.)
- Recent activity logs
- Quick links to management modules

## Modules

- **User Management:** Add/edit/delete users, assign roles, bulk import/export.
- **Survey Management:** Create/manage surveys, view responses.
- **Ticket Management:** Assign, resolve, close, or delete tickets.
- **Logs:** View/download logs, clear logs.
- **Backup:** Create/download system backups.
