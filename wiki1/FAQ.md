# ❓ FAQ

**Q: What are the default admin credentials?**  
A: Set during installation or check with your system administrator.

**Q: How do I reset a user password?**  
A: Admins can reset passwords from User Management.

**Q: Can I import users in bulk?**  
A: Yes, via CSV import in User Management.

**Q: How do I update the system?**  
A: Pull the latest code and follow the upgrade instructions in the release notes.
