# 🛠️ Troubleshooting

## Common Issues

- **Blank page:** Check PHP error logs and file permissions.
- **Database errors:** Verify DB credentials and imported schema.
- **Login issues:** Clear browser cache, check sessions, reset password.
- **File upload errors:** Ensure `uploads` folder is writable.

## Logs

- View logs in the `logs/` directory or via the Admin panel.
